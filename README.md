# Chatbot:

## Project Description
This is a simple rule-based chatbot developed using Python. It interacts with users by accepting text input and providing predefined responses.
## Features
- Greets the user when they type "hello".
- Responds to "how are you".
- Displays a goodbye message when the user types "bye".
- Handles unknown inputs with a default response.
- Runs continuously until the user exits.
## Technologies Used
- Python
## Concepts Used
- Functions
- While Loop
- If-elif-else Conditional Statements
- User Input
- String Methods
## How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python editor.
4. Run the following command:
```
python chatbot.py
```
